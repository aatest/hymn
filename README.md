# ♪ 찬송가 · 복음성가 악보 뷰어

단일 HTML 파일로 동작하는 악보 관리 앱입니다.
설치 없이 브라우저에서 바로 사용할 수 있으며, 아이패드 사파리·안드로이드(삼성인터넷 포함)에서도 동작합니다.

---

## 시작하기

### 로컬 사용
`hymn-viewer.html` 파일을 브라우저로 열면 바로 사용 가능합니다.

### 모바일(아이패드·휴대폰) 사용
GitHub Pages로 접속하는 방식을 권장합니다.

1. GitHub 저장소에 `hymn-viewer.html` 업로드
2. Settings → Pages → Branch: main 저장
3. 생성된 주소를 브라우저에서 접속

```
https://아이디.github.io/저장소명/hymn-viewer.html
```

주소창에서 **공유 → 홈 화면에 추가** 하면 앱처럼 사용할 수 있습니다.

## 주요 기능

### 악보 목록 관리
- **악보 추가**: 구분(찬송가/복음성가), 번호, 제목, 이미지 등록
- **찬송가 목차에서 악보 추가**: 새찬송가 1~645장 전체 검색 후 원클릭 등록
- **복음성가 목차에서 악보 추가**: 복음성가 목록 검색 후 원클릭 등록
- **검색**: 번호 또는 제목 키워드로 실시간 검색 (목록 바로 위)
- **필터**: 전체 / 찬송가 / 복음성가 탭 전환
- **순서 변경**: 드래그 앤 드롭 (PC 마우스 / 모바일 길게 눌러 끌기)
- **삭제**: 항목의 ✕ 버튼

### 악보 매칭 폴더 (목차에서 자동 연결)
"📖 찬송가 목차에서 악보 추가" 모달 안에서 **악보 이미지 폴더를 한 번 선택**하면, 목록의 각 곡 번호에 맞는 악보 이미지가 자동으로 연결됩니다.
- 폴더를 고르기 전에는 안내 문구와 **📁 악보 폴더 선택** 버튼이 보입니다.
- 폴더를 고르면 "N개 파일에서 M곡 인식됨"이 표시됩니다.
- 파일명에 들어 있는 장 번호(예: `새찬송가026장_...`, `26 구세주를 아는 이들...`)로 매칭합니다.

### 악보 뷰어
- 이미지를 화면에 맞게 **자동 크기 조정** (사이드바를 열고 닫거나 화면을 회전해도 다시 맞춰짐)
- 이전/다음 페이지 이동 (버튼·하단 썸네일·모바일 스와이프)
- 확대/축소 (＋ / − / ⊙ 버튼 또는 키보드)
- 제목 앞에 **찬송가/복음성가 태그** 표시
- 하단 썸네일 **＋** 버튼으로 페이지 추가

### 곡 간 연속 이동
- 뷰어 상단 **«** / **»** 버튼으로 이전/다음 곡 이동
- 마지막 페이지에서 **›** → 다음 곡 첫 페이지로 자동 이동
- 첫 페이지에서 **‹** → 이전 곡 마지막 페이지로 자동 이동

### 저장 / 불러오기
- **💾 저장**: 이미지 포함 전체 목록을 `.json` 파일로 내보내기
- **📂 불러오기**: 저장한 `.json` 파일을 불러와 목록 복원
  - 기존 목록이 있으면 **추가** 또는 **교체** 선택
  - 중복 항목은 자동 제외

## 키보드 단축키

| 키 | 동작 |
|----|------|
| `←` / `→` | 이전/다음 페이지 (곡 경계 자동 이동) |
| `Shift + ←` / `Shift + →` | 이전/다음 곡 |
| `+` | 확대 |
| `-` | 축소 |
| `0` | 원래 크기 |

---

## 데이터 저장 방식

- 목록 데이터는 브라우저 **IndexedDB**(`HymnViewerDB`)에 자동 저장됩니다.
  - 이전 버전에서 쓰던 localStorage 데이터가 있으면 처음 실행 시 자동으로 옮겨집니다.
- 이미지는 **Base64**로 변환되어 함께 저장됩니다.
- 저장/불러오기(`.json`) 기능으로 기기 간 데이터 이동이 가능합니다.
- 데이터는 해당 기기의 브라우저에 저장됩니다 (서버 전송 없음).

## 모바일 호환성 메모

- 안드로이드/삼성인터넷의 **자동 글자 확대(폰트 부스팅)**를 꺼서 제목·텍스트가 비정상적으로 커지지 않습니다.
- `100vh` 대신 **실제 보이는 화면 높이**를 사용해, 하단 브라우저 툴바에 썸네일 줄이 가려지지 않습니다.
- 좁은 화면에서는 뷰어 상단이 **제목 줄 / 페이지·확대 줄 2행**으로 나뉩니다.
- 핀치 줌 후 화면이 어긋나면 1배로 돌아올 때 위치를 자동 보정합니다.
